# Avisos y Promedios (A&P)

Aplicación para consultar horarios, tareas y evaluaciones, organizar la semana y seguir tus notas y promedios.

## Descargar para Android

**[Descargar la última versión de A&P](https://github.com/Maximo4250/Avisos-y-Promedios/releases/latest/download/app-release.apk)**

El enlace descarga directamente `app-release.apk`, sin páginas intermedias. Requiere Android 7.0 o posterior.

## Instalar o actualizar

1. Tocá el enlace de descarga desde tu celular.
2. Abrí el archivo descargado.
3. Si Android lo solicita, autorizá la instalación desde el navegador y elegí Instalar o Actualizar.

## Funciones

- Horario por día y modo Pendientes semana.
- Tareas con progreso guardado en el dispositivo.
- Fechas de exámenes y prioridades.
- Notas, promedios, gráficos y datos de cursada.

[Ver versiones y novedades](https://github.com/Maximo4250/Avisos-y-Promedios/releases)

Este repositorio se utiliza para distribuir los instaladores de la aplicación.
